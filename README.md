# STASH Extension

STASH Extension — независимые инструменты для Axiom и X.

## Модули

- **LastATH** — история предыдущих запусков разработчика.
- **Migration Percent** — процент миграций разработчика по X/Y.
- **Axiom Stretch** — настройка масштаба рабочей области Axiom.
- **Usernames** — дополнительные подписи и информация о пользователях.
- **Dev Glow** — подсветка отслеживаемых разработчиков и кошельков.
- **Pump & Twitter** — информация о токене и связанные социальные данные.
- **Translator** — перевод публикаций на X и поддерживаемых текстов в Axiom.

Модули включаются и настраиваются отдельно.

## Требования

- Google Chrome 116 или новее.
- Для AI-перевода — собственный API-ключ выбранного провайдера. Быстрый перевод доступен отдельно.

## Установка ZIP

1. Скачайте и распакуйте ZIP в отдельную папку.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите папку, внутри которой находится `manifest.json`.
6. Откройте Axiom или X и обновите вкладку.

Для обновления замените файлы в папке, нажмите **Обновить** на странице расширений и перезагрузите вкладки Axiom/X.

## Настройки и данные

Настройки хранятся в локальном хранилище Chrome. API-ключи для AI-перевода пользователь вводит самостоятельно в разделе Translator; ключи нельзя добавлять в исходный код или ZIP.

При переводе текст отправляется выбранному сервису. Учитывайте политику конфиденциальности выбранного провайдера.
